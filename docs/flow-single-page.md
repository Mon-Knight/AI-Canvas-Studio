# 单页使用 Flow 积分：在 Flow 项目内运行

这是现有本地画布之外的一条路线，不会改变画布的账号或计费。它把唯一的工作页面换成 Flow 项目本身，既不启动本地扩展，也不用配置 Google 视频 API Key。它不代表本地画布已经能在 Flow 页面关闭后提交生成。

## 在 Flow 中创建工具

使用具有创建工具权限的账号，在 Flow 项目中选择 **Tools → Create Tool**，粘贴下方说明。先检查生成的界面，再保存；预览界面不需要实际提交测试视频。创建权限、积分提醒和保存项目的行为见 [Google Flow Tools 官方说明](https://support.google.com/flow/answer/17104535?hl=en)。

### 可直接粘贴的工具说明

> 在当前 Flow 项目中创建一个简体中文的「镜头工作台」视频工具。第一步，让我粘贴已经选好的提示词，显示完整内容并允许编辑。第二步，让我按当前项目和模型支持的方式选择参考图片、画幅和视频模型。第三步，在同一面板展示本次生成的设置，并给出明确的「生成视频」按钮。仅当我点击该按钮时，才调用 Flow 自带的视频生成能力；粘贴、编辑、切换模型和刷新都不要提交生成。保留 Flow 自身的积分提醒，不估算余额，不索取 API Key。只显示平台实际返回的任务状态：没有进度数据时显示「等待结果」，不要编造百分比。生成后在同一界面播放结果，素材归入当前项目。重复点击时避免重复提交；失败后由我决定是否重试。如果某项控件或状态未由平台提供，请省略，不要制作模拟结果。

这是一份创建说明，不是已部署的工具。Flow 工具不会自动继承本地画布的节点、聊天记录或密钥；不要将外部 AI 的密钥粘贴到工具说明或写入工具代码。

## 如果电脑只保留本地画布，生成时不挂网页或扩展

如果接受**在手机上点一次生成**，可以在 Google Flow 官方移动应用中操作：

1. 在本地画布准备并复制提示词。在手机的 Flow 应用中确认登录的是同一个 Google 账号，进入目标项目，粘贴提示词；需要首帧时，在手机上选择图片。
2. 选择「视频」、模型、画幅和输出数量，在应用中确认并提交。扣的是该账号在 Flow 中的积分，不需要视频 API Key 或独立的 Google Cloud 计费项目。
3. 提交后可以关闭移动应用，电脑继续只开本地画布。启用手机推送后可收到 Flow 通知，点开应用查看结果。结果在 Flow 项目中，本地画布不会因此自动取得任务状态或成片。

参考：[在 Flow 应用中创建视频](https://support.google.com/flow/answer/16353334?co=GENIE.Platform%3DAndroid&hl=en)、[移动应用关闭后的通知](https://support.google.com/flow/answer/16353335?co=GENIE.Platform%3DAndroid&hl=en)、[账号的 Flow 积分](https://support.google.com/flow/answer/16526234?hl=en)。

**如果连提交也必须在本地画布完成**：目前未查到供外部画布直接提交视频并扣个人 Flow 积分的公开 Google 接口。此项目的画布提交仍要求选中的账号、绑定的项目、对应的 Flow 网页和扩展在线；断开时不提交，也不切换到其他计费方。
