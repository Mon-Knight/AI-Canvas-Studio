# 从创意分析到画布视频

**创意分析和视频生成分开计费。** 分析使用外部 OpenAI API Key；视频只使用右上角选中的 Flow 账号、网页会话和项目，不需要 Google 视频 API Key。

## 准备账号

1. 在「与 AI 对话」的模型设置保存 OpenAI API Key。使用「创意分析」时，文字、画布摘要和本次附图会发给外部模型；分析只返回建议，不生成视频。没有密钥时，分析不会切换到本机 CLI 或其他服务。
2. 在右上角头像菜单添加或切换 Flow 账号，打开该账号专用的 Chrome 配置，在 Flow 官网登录并绑定项目。首次使用时配对扩展；生成期间保持同一账号的网页和扩展在线。[账号与配对说明](flow-accounts.md)
3. 确认 Flow 网页登录的是想使用的账号。画布显示的是配对资料，不代替官网验证；账号旁的手动积分记录仅供参考，空白不等于零，任务最终扣费和余额以 Flow 官网为准。

## 从草稿到预览

1. 在对话中选好建议后，点击「用作视频提示词」，可填入已有视频节点，也可以新建视频节点。画布会定位到目标节点；填入草稿不会提交计费任务。
2. 在节点下方确认提示词、参考变体、画幅、模型和 Flow 账号，然后点击生成。Veo 图生视频需要选中的源图像；Omni Flash 使用连入的参考图。切换账号或项目后，请重新确认再提交。
3. 节点显示「排队中」「生成中」和最终结果，不估算完成百分比。成功后直接在节点内播放，可逐个预览变体。若重试失败，已生成的上次结果会保留。
4. 如果扩展断开，先检查对应账号的 Chrome 窗口；如果任务超时，先到 Flow 官网核对生成记录，再决定是否重新提交。刷新画布只恢复状态跟踪，不会重新提交任务。
